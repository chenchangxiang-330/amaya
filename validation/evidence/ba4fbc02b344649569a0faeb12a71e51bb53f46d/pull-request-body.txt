Adds Simplified Chinese for the core local Android flows, retaining English defaults, existing layouts and behavior, the Amaya name, attribution, and license. Uses 477 Android string/plural resources with locale-aware access in Compose and non-Composable entry points; no dependency upgrades or custom translation framework.

**Coverage:** home/navigation; chat composer, common actions and confirmations; projects, workspace browser and references; agent groups/configuration; models, providers, API setup and input validation; common settings, theme/language, update UI, terminal policy and accessibility labels. Machine identifiers, API addresses, protocol fields, commands and paths are unchanged.

**Language selection:** Settings → Appearance → Language → Follow system / 简体中文 / English. AppCompat persists selection on Android 12 and earlier and integrates with platform app locales on Android 13+. User-entered Chinese names/content survive switching and restart.

Chinese reference filenames now preserve Unicode letters, combining marks and numbers while excluding separators/control characters; unit tests cover this. Separate commit `358531f` fixes the existing API-26 update compatibility error using the already available `PackageInfoCompat.getLongVersionCode`.

### Limits

This is a first pass over core flows. Advanced remote/bridge, MCP/scheduling, detailed tool output and browser automation still contain English. Raw technical/runtime/server error details remain unchanged; Android owns system picker/permission text.

No authorized model API credentials were available. Tests used `https://example.invalid/v1` without a key; no real or mocked successful model reply is claimed. Real replies, tool execution and model-driven use of references remain unverified. Physical ARM64 execution, release signing and a full TalkBack/device-layout audit were not performed.

API 35 emulator attempts repeatedly lost their emulator process/ADB connection; the host cause is unresolved. API 35 is not counted as passed. Final API 30 and 33 runs completed successfully.
