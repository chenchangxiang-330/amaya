Root causes and implementation
The project Workspace row called an empty click handler. It now launches the existing file browser at the saved workspace path in a browsing mode. The folder-selection action remains reserved for project creation/selection. Browsing does not update a project's root path. Folder navigation and Back return through browsing history. Missing/unreadable folders show a localized error and Retry; permission changes trigger a reload.
Reference rows previously opened removal confirmation on every tap. A row now opens the reference content, while its separate named remove button retains confirmation. This shared list also serves agent/group references; runtime coverage in this task focuses on projects.
LocalFileViewerActivity provides a read-only text viewer with selection, offline HTML using the existing HtmlPreviewCard, and images via the existing Coil dependency. Other formats provide an explicit Open with another app action using the existing FileProvider and a temporary read grant. No provider roots or dependencies were added.
LocalFilePreview bounds text reads to 200,000 characters and reports truncation without altering the source. It handles UTF-8 and BOM-marked UTF-16, and keeps unsupported binary types out of the text renderer. Missing/unreadable files show an error. Project detail reloads its record on resume before enabling edits so a later name/instructions save retains references added in another Activity.
Visual review of the first fully passing run (43163624614, source b8792a000d0f1d7ccb8735d5b49e03c2661a4963) found that the settings-style top scrim faded the first text line and image edge. The final viewer uses a fixed Material app bar and a separate scrollable content viewport. Runtime checks now sample the image color to catch this regression.
No database schema, model/provider protocol, agent engine or workspace assignment was changed. Ten new English/Chinese resources were added. The source branch is separate from the Fork validation/evidence branches and no new upstream PR was created by this task.

Limits / not verified
No real model response or API credentials were used. Offline-provider failure in the setup is expected, not a successful AI response.
Native text preview supports UTF-8 and BOM-marked UTF-16; other encodings can be opened in a supporting external application. Large text is intentionally truncated in the viewer. The viewer is read-only; reference editing was not added.
PDF/Office/other unsupported formats rely on an installed external viewer; the presence and behavior of such third-party applications were not validated. HTML keeps the previous offline-preview restrictions: no CDN, external API or backend server. No real-user files or the user's physical phone were accessed.
Permission-denial behavior, large-font rendering, screen-reader operation and agent/group reference routes were not newly runtime-tested. Existing photos, model capability and conversation rename fixes are inherited from the baseline; this task does not claim a fresh complete regression run for them.
