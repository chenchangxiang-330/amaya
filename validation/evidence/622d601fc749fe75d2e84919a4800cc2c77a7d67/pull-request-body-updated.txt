Adds Simplified Chinese to the core Android flows using 483 Android string/plural resources, retaining English defaults, existing layouts, the Amaya name, attribution and license. Uses AppCompat application locales with no dependency upgrades or custom translation framework.

**Coverage:** home/navigation; chat composer and common actions; projects, workspace browsing and references; agent groups/configuration; models, providers and API setup; common settings, language/theme, update UI, terminal policy and accessibility labels. Machine identifiers, URLs, commands, protocol fields and system prompts are unchanged.

**Language:** Settings → Appearance → Language → Follow system / 简体中文 / English. Selection persists on Android 12 and earlier and integrates with platform app locales on Android 13+. Chinese names and content survive language changes and restart.

**Core-flow fixes included:**
- File-picker results now update composer attachment state. PNG/JPEG photos selected through Add file use ContentResolver and the existing image-message path, with bounded decoding and visible read errors.
- Long-press a local/project conversation to rename it. Empty titles are rejected; conversation ID, ownership and messages are preserved. Manual titles are protected from automatic title generation.
- Chinese reference filenames preserve Unicode letters, marks and numbers. A separate commit fixes the pre-existing API-26 version-accessor lint error using PackageInfoCompat.getLongVersionCode.
- When an image is rejected by a model without image support, retain the attachment and typed text.

Saved conversation IDs and messages were compared across renaming and restart.

### Limits
No live API credentials or simulated successful model responses were used. Tests validate configuration, client attachment handling, persistence and unavailable-service behavior; real model receipt, vision responses and dependent end-to-end flows remain unverified. The non-vision-model draft-restoration branch was statically reviewed but not separately exercised by the UI suite. Physical ARM64 devices, every image format/orientation and full accessibility coverage were not tested. System picker text belongs to Android; low-level/provider error details and deferred remote/bridge surfaces may remain English. Long chat titles retain the existing fade/truncation behavior.
